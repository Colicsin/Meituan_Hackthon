# 智行伴侣 - 命题强化报告

## 一、命题核心要求

根据Hackathon命题解读，评分关注三大维度：

| 维度 | 核心要求 |
|------|----------|
| **完整性** | 路线规划满足时间、距离、预算、偏好、排队等约束 |
| **创新性** | 交互方式新颖，过程透明化，避免用户"傻等" |
| **应用效果** | 响应<10秒，POI覆盖餐饮/娱乐/文化，支持3个POI串联 |

---

## 二、强化前差距分析

### 缺失功能

| 功能 | 原状态 | 命题要求 |
|------|--------|----------|
| 用户画像识别 | ❌ 无 | 需识别独自/情侣/家庭/朋友，差异化推荐 |
| 差异化推荐 | ⚠️ 弱 | 同一需求应对不同用户给出不同结果 |
| 规划过程透明化 | ❌ 无 | 展示"理解需求→筛选POI→生成路线"过程 |
| 实时反馈调整 | ❌ 无 | 支持"太远了"、"不想排队"动态调整 |
| 排队数据 | ❌ 无 | 需要排队时间，辅助决策 |

### 已满足要求

| 功能 | 状态 | 说明 |
|------|------|------|
| 响应时间<10秒 | ✅ 已满足 | 实测<1秒 |
| 3个POI串联 | ✅ 已满足 | 支持5-7个POI |
| POI类型覆盖 | ✅ 已满足 | 餐饮、咖啡、酒吧、书店、公园、电影院等 |
| 多轮对话 | ✅ 已满足 | Decision Agent支持槽位填充 |

## 三、强化实现方案

### 3.1 用户画像识别（核心创新）

**实现文件：** `backend/app/api/smart_plan.py`

**画像类型：**
```python
USER_PROFILES = {
    "solo": {      # 独自出行
        "keywords": ["安静", "平和", "一人食", "独处"],
        "avoid": ["聚会", "热闹", "排队"]
    },
    "couple": {    # 情侣约会
        "keywords": ["浪漫", "氛围", "约会", "有情调"],
        "avoid": ["热闹", "聚会", "嘈杂"]
    },
    "family": {    # 家庭出游
        "keywords": ["亲子", "儿童友好", "不辣", "健康"],
        "avoid": ["酒吧", "夜店", "排队久"]
    },
    "friends": {   # 朋友聚会
        "keywords": ["热闹", "聚会", "氛围好", "好玩"],
        "avoid": ["安静", "一人食", "沉闷"]
    }
}
```

**识别逻辑：**
```python
def detect_user_profile(text: str) -> str:
    if any(k in text for k in ["一个人", "独自", "我一人"]):
        return "solo"
    if any(k in text for k in ["情侣", "约会", "女友", "男友"]):
        return "couple"
    if any(k in text for k in ["孩子", "带娃", "家庭", "全家"]):
        return "family"
    if any(k in text for k in ["朋友", "聚会", "一群人"]):
        return "friends"
```

### 3.3 实时反馈调整（差异化能力）

**API：** `POST /smart-plan/adjust`

**支持的反馈类型：**
```python
if "远" in feedback:
    # 筛选路程<15分钟的地点
    filtered = [item for item in items if item["travel_time_min"] < 15]

if "排队" in feedback:
    # 排除排队>20分钟的商家
    filtered = [item for item in items if item["queue_time_min"] < 20]

if "贵" in feedback:
    # 筛选人均<80元的地点
    filtered = [item for item in items if item["avg_price"] < 80]
```

### 3.4 排队情况数据

**实现方式：** 模拟排队时间

```python
def get_queue_time(poi_id: str, hour: int) -> int:
    # 基于POI ID和时段生成排队时间
    base = random.randint(0, 60)
    
    # 高峰期（11-13点，17-19点）排队更长
    if 11 <= hour <= 13 or 17 <= hour <= 19:
        return base + random.randint(20, 40)
    return base
```

**展示方式：**
- 排队≤20分钟：绿色标签 `排队15分钟`
- 排队>30分钟：红色标签 `排队45分钟`

## 八、技术亮点

### 8.1 用户画像建模
- 自动识别4种画像类型
- 每种画像有独立的偏好关键词
- 避免推荐与画像冲突的POI

### 8.2 规划过程透明化
- 5步流程可视化
- 动画渐进展示
- 用户清楚知道系统在做什么

### 8.3 差异化推荐
- 同一输入 + 不同画像 = 不同结果
- 示例：同样说"周末玩一天"
  - 独自 → 安静咖啡厅 + 书店
  - 情侣 → 浪漫餐厅 + 爵士酒吧
  - 家庭 → 公园 + 亲子餐厅
  - 朋友 → 热闹火锅 + KTV

### 8.4 实时反馈响应
- 支持"太远"、"不想排队"、"太贵"等反馈
- 即时重新筛选并返回调整后的结果
