# 智行伴侣 - 部署指南

## 方案一：队友独立运行（推荐）

队友自己运行前后端，独立开发测试。

### 1. 克隆项目

```bash
git clone https://github.com/Colicsin/Meituan_Hackthon.git
cd Meituan_Hackthon
git checkout dev
```

### 2. 后端设置

```bash
cd hackathon/backend

# 创建虚拟环境
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # Mac/Linux

# 安装依赖
pip install fastapi uvicorn sqlalchemy httpx pydantic-settings sentence-transformers

# 启动后端
python -m uvicorn app.main:app --host 0.0.0.0 --port 8002
```

### 3. 前端设置

```bash
# 新开终端
cd hackathon/frontend

# 安装依赖
npm install

# 启动前端
npm run dev
```

### 4. 访问

打开浏览器：http://localhost:5173

## 方案二：局域网共享

一人运行服务，其他人通过IP访问。

### 1. 查看你的IP

```bash
# Windows
ipconfig

# Mac/Linux
ifconfig
```

找到类似 `192.168.1.100` 的地址。

### 2. 启动服务

**后端：**
```bash
cd hackathon/backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8002
```

**前端：**
```bash
cd hackathon/frontend
npm run dev:share  # 注意：用 dev:share 不是 dev
```

### 3. 告诉队友访问地址

```
前端：http://你的IP:5173
例如：http://192.168.1.100:5173

后端API：http://你的IP:8002
```

### 4. 队友访问

队友在浏览器输入：`http://你的IP:5173`

## 常见问题

### Q: 队友访问显示"网络错误"？

**A:** 检查以下几点：

1. **同一局域网**：确保你们连同一个WiFi或热点
2. **防火墙**：Windows防火墙可能阻止访问
   ```bash
   # 临时关闭防火墙（管理员权限）
   netsh advfirewall set allprofiles state off
   ```
3. **端口正确**：
   - 后端必须用 `--host 0.0.0.0`（不能是127.0.0.1）
   - 前端必须用 `npm run dev:share`
4. **IP正确**：用 `ipconfig` 确认你的局域网IP

### Q: 如何测试后端是否可访问？

队友浏览器输入：`http://你的IP:8002/health`

应该返回：`{"status":"ok"}`

### Q: 前端启动后显示 Network 地址？

正确！Vite会显示两个地址：
```
Local:   http://localhost:5173/
Network: http://192.168.1.100:5173/
```

队友用 **Network** 地址访问。
