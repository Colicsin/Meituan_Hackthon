# 快速公网部署方案

## 方案一：ngrok（临时分享，最快）

### 1. 下载ngrok

https://ngrok.com/download

### 2. 注册并获取Token

https://ngrok.com 注册账号，复制Authtoken

### 3. 配置

```bash
ngrok config add-authtoken 你的token
```

### 4. 启动本地服务

```bash
# 终端1：后端
cd hackathon/backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8002

# 终端2：前端
cd hackathon/frontend
npm run dev
```

### 5. 启动ngrok

```bash
# 终端3：前端隧道
ngrok http 5173

# 终端4：后端隧道
ngrok http 8002
```

### 6. 获得公网地址

ngrok会显示：
```
Forwarding    https://abc123.ngrok.io -> http://localhost:5173
```

把这个地址发给队友：`https://abc123.ngrok.io`

**任何人都能访问，不限WiFi！**

## 方案二：Vercel（永久部署，免费）

### 前端部署

```bash
cd hackathon/frontend

# 安装Vercel CLI
npm i -g vercel

# 登录
vercel login

# 部署
vercel

# 部署生产环境
vercel --prod
```

获得地址：`https://智行伴侣.vercel.app`

### 后端部署（Railway）

1. 访问 https://railway.app
2. Start New Project → Deploy from GitHub repo
3. 选择 Meituan_Hackthon 仓库
4. Root Directory: `hackathon/backend`
5. 自动部署

获得地址：`https://智行伴侣-backend.railway.app`

### 修改前端API地址

更新 `frontend/src/config/api.ts`：

```typescript
const API_BASE_URL = import.meta.env.VITE_API_URL || 
  (import.meta.env.DEV ? 'http://localhost:8002' : 'https://智行伴侣-backend.railway.app');
```

## 方案三：阿里云服务器（生产级）

### 1. 购买服务器

访问 https://www.aliyun.com/product/ecs
选择：2核2G，约100元/月

### 2. 连接服务器

```bash
ssh root@你的公网IP
```

### 3. 一键部署脚本

创建 `deploy.sh`：

```bash
#!/bin/bash

# 安装依赖
apt update
apt install -y python3 python3-pip nodejs npm nginx

# 克隆代码
cd /root
git clone https://github.com/Colicsin/Meituan_Hackthon.git
cd Meituan_Hackthon

# 后端
cd hackathon/backend
pip3 install -r requirements.txt
nohup python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8002 &

# 前端
cd ../frontend
npm install
npm run build
```

### 4. 配置Nginx

```nginx
server {
    listen 80;
    server_name 你的域名.com;

    # 前端
    location / {
        root /root/Meituan_Hackthon/hackathon/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端API
    location /api {
        proxy_pass http://127.0.0.1:8002;
    }
}
```

### 5. 访问

```
http://你的域名.com
```
