### 1. `backend/app/services/embedding.py` （核心修改）

**修改内容：支持本地模型加载，解决下载慢问题**

```python
# 修改前（需要从HuggingFace下载409MB模型）
def get_model():
    global _model
    if _model is None:
        print("正在加载向量模型，首次运行需要下载...")
        
        if os.getenv('USE_SMALL_MODEL', 'false').lower() == 'true':
            print("使用小模型模式（50MB）")
            _model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')
        else:
            _model = SentenceTransformer('shibing624/text2vec-base-chinese')
        
        print("✅ 模型加载完成")
    return _model

# 修改后（优先使用本地模型）
import os
from pathlib import Path

# 本地模型路径：backend/models/text2vec-base-chinese/
_LOCAL_MODEL_DIR = Path(__file__).resolve().parents[2] / "models" / "text2vec-base-chinese"

def get_model():
    global _model
    if _model is None:
        # 优先从本地加载
        if _LOCAL_MODEL_DIR.exists() and (_LOCAL_MODEL_DIR / "config.json").exists():
            print(f"📦 从本地加载向量模型: {_LOCAL_MODEL_DIR}")
            _model = SentenceTransformer(str(_LOCAL_MODEL_DIR))
        else:
            # 本地没有才下载
            print("⚠️ 本地模型不存在，尝试从 HuggingFace 下载（需要网络）...")
            _model = SentenceTransformer('shibing624/text2vec-base-chinese')
        
        print("✅ 模型加载完成")
    return _model
```

**优点：**
- ✅ 如果本地有模型（`backend/models/text2vec-base-chinese/`），直接加载，无需下载
- ✅ 本地没有时仍可从HuggingFace下载
- ✅ 解决了首次运行下载慢的问题

**使用方法：**
1. 手动下载模型到 `backend/models/text2vec-base-chinese/`
2. 或让系统自动下载（首次运行）
