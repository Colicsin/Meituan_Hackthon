================================================================================
一、项目概述
================================================================================

1.1 项目定位
智行伴侣是一个基于AI的出行便利与行程优化系统，为用户提供：
- 情绪驱动的商家推荐
- 智能行程规划（多种路线方案）
- 途中小憩推荐
- 微气候路线建议

1.2 核心价值主张
情绪输入 → AI推荐 → 用户选择 → 行程规划 → 地图展示 → 体验优化

1.3 技术栈
前端：
- React 18.x + TypeScript 5.x
- Vite 5.x 构建工具
- TailwindCSS 样式框架
- 高德地图 JS API
- 状态管理：useState Hooks

后端：
- FastAPI (Python 3.10+)
- sentence-transformers (文本向量化)
- Pydantic 数据验证
- httpx 异步HTTP客户端

AI能力：
- Vibe Agent：情绪文本匹配
- Itinerary Agent：行程规划算法
- LLM Client：统一LLM调用接口

Phase 2：AI Agent实现 ✅

【N9: Vibe Agent（情绪匹配Agent）】

功能：根据用户情绪文本推荐匹配商家

核心逻辑：
用户输入情绪文本 
  → 文本向量化（sentence-transformers）
  → 计算与所有商家的相似度
  → 返回Top-K匹配结果

文件：
- backend/app/services/embedding.py - 文本向量化
- backend/app/agents/vibe_agent.py - 情绪匹配Agent
- backend/app/api/vibe.py - API接口

测试结果：
- 匹配度范围：70%-90%
- 响应时间：<500ms

--------------------------------------------------------------------------------

【N10: Itinerary Agent（行程规划Agent）】

功能：根据用户选择的POI生成多种路线方案

算法实现：
1. 最快路线：贪心算法选择最近点
2. 最优路线：平衡评分与距离
3. 最省路线：按价格排序访问

文件：
- backend/app/agents/itinerary_agent.py - 行程规划Agent
- backend/app/utils/helpers.py - 工具函数（Haversine距离计算）
- backend/app/api/itinerary.py - API接口

输出内容：
- 每个地点的到达/离开时间
- 步行距离和时长
- 总路程、总耗时、人均消费

六、演示流程
================================================================================

完整演示步骤

准备工作：
1. 启动后端：cd backend && python run.py（端口8001）
2. 启动前端：cd frontend && npm run dev（端口5175）

演示流程：

第1步：情绪输入
访问 http://localhost:5175
点击"🎉 热闹开心"按钮

第2步：查看推荐
等待API返回，查看5个匹配商家
观察匹配度进度条（70%-90%）

第3步：选择商家
勾选2-3个感兴趣的商家
观察选中状态（紫色边框+背景）

第4步：生成路线
点击"🗺️ 生成路线 (3 个地点)"按钮
等待规划完成

第5步：查看路线方案
查看3种路线：
- 最快路线（距离最短）
- 最优路线（平衡评分和距离）
- 最省路线（价格最低）

第6步：查看详细时间
展开任意路线卡片
查看每个地点的：
- 到达时间、离开时间
- 停留时长、步行距离
- 评分、人均消费

第7步：地图预览
滚动到"🗺️ 路线地图预览"
观察高德地图上的标注和连线

第8步：途中小憩
点击"😊 我累了，想休息"按钮
查看附近9个休憩点
观察设施标签（有顶棚、有靠背、免费）

第9步：微气候路线
点击"🌳 走阴凉路线"按钮
查看体感温度提示（降低2-3℃）
查看5个阴凉路段详情

总演示时长：约3-5分钟
